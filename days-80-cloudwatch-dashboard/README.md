# Day 80 — CloudWatch Dashboard

## What We Are Studying
CloudWatch Dashboards provide a single view of multiple EC2 metrics and alarms.
Dashboards help engineers monitor instance health at a glance.

## Commands Used
| Command | Purpose |
|---------|---------|
| `aws cloudwatch put-dashboard` | Creates or updates a dashboard |
| `aws cloudwatch get-dashboard` | Retrieves dashboard definition |
| `aws cloudwatch list-dashboards` | Lists all dashboards |
| `aws cloudwatch delete-dashboards` | Deletes a dashboard |
