# Day 173 — Networking: Connect with 15 cloud recruiters and engineers on LinkedIn

## Goal

Connect with 15 real cloud recruiters and engineers on LinkedIn using professional, personalized connection requests. Dev sends every request and message by hand; no fake profiles, companies, or claims.

## Networking Rules

- Connect only with real LinkedIn profiles.
- Prioritize recruiters and engineers working in cloud, DevOps, SRE, infrastructure, or cloud support.
- Focus on Gujarat, Mumbai, Pune, and remote India opportunities.
- Personalize each note using information visible on the recipient’s profile.
- Do not copy the same note to every person.
- Do not ask for a job in the first message.
- Do not claim experience, employers, metrics, salaries, or skills not demonstrated in the projects.
- Do not include `.env`, credentials, account IDs, or private keys.
- Record every connection request and follow-up in the tracker.

## Connection Note Templates

Use one of these short templates and replace only the bracketed fields with real profile details.

### Recruiter Note

```text
Hi [FIRST NAME], I came across your profile and noticed your work in cloud and technology recruitment. I am a cloud and DevOps fresher with hands-on projects in Terraform, AWS, Docker, GitHub Actions, and monitoring. I am exploring entry-level Cloud, DevOps, Cloud Support, and Site Reliability opportunities in India. I would be glad to connect and learn from your insights.
```

### Cloud Engineer Note

```text
Hi [FIRST NAME], I found your profile through your work in [CLOUD/DEVOPS/SRE AREA]. I am building hands-on experience with Terraform, AWS, Docker, Nginx, GitHub Actions, and monitoring. I recently completed projects involving AWS infrastructure, CI/CD deployments, rollback automation, and CloudWatch-based monitoring. I would be glad to connect and learn from your experience.
```

### SRE Engineer Note

```text
Hi [FIRST NAME], I came across your profile and was interested in your work in reliability and cloud operations. I have built hands-on projects using AWS, Terraform, Docker, GitHub Actions, CloudWatch alarms, SNS alerts, and S3 backups. I am exploring entry-level Site Reliability and Cloud Operations opportunities in India and would be glad to connect.
```

## Follow-Up Rule

If a connection accepts, wait before sending a follow-up. Use a short, respectful message only if appropriate:

```text
Thank you for connecting, [FIRST NAME]. I am exploring entry-level Cloud, DevOps, Cloud Support, and Site Reliability opportunities in India. I have built hands-on projects using Terraform, AWS, Docker, GitHub Actions, and monitoring. If you are aware of a suitable opportunity, I would appreciate any guidance you can share.
```

Do not send repeated messages if there is no response.

## Quality Checklist

Before sending each request, confirm:

1. The profile is real and relevant to cloud, DevOps, SRE, or technical recruitment.
2. The person’s location or company is relevant to the target market.
3. The note uses a real detail from their profile.
4. The note is short, respectful, and free of job-demand language.
5. The note does not claim unverified experience.
6. The request is recorded in the tracker.

## Rules

- Dev sends all LinkedIn connection requests and messages by hand.
- Use only real people, companies, and profile details.
- Do not invent experience, employers, metrics, salaries, or company names.
- Do not include `.env`, credentials, account IDs, or private keys in any message.
