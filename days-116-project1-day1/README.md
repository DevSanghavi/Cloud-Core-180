# Day 116/180 — Project 1, Day 1: Project Planning
## Project: Terraform AWS Infrastructure
This project builds a reusable, secure AWS infrastructure using Terraform. It will create a custom VPC with public/private subnets, an EC2 application server, an RDS database, security groups, and an S3 bucket for Terraform remote state. The stack uses AWS Free Tier resources and follows infrastructure-as-code best practices.
