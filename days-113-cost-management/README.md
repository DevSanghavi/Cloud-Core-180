# Day 113 — AWS Cost Management
## What We Are Studying
AWS Billing Dashboard shows real-time spending. Free Tier has monthly limits per service. Budgets and CloudWatch alarms notify you before costs exceed thresholds.
## Commands Used
| Command | Purpose |
|---------|---------|
| `aws budgets create-budget` | Create spending budget |
| `aws ce get-cost-and-usage` | Query cost data |
| `aws cloudwatch put-metric-alarm` | Create billing alarm |
| `aws budgets describe-budgets` | List existing budgets |
