# Day 89 — Terraform Variables & Outputs (maps and lists)
## What We Are Studying
Input variables with complex types (maps, lists) enable reusable Terraform modules. Outputs expose structured data for downstream use.
## Commands Used
| Command | Purpose |
|---------|---------|
| `terraform init` | Initialize directory and download providers |
| `terraform plan -var-file=dev.tfvars` | Preview with variable overrides |
| `terraform output -json` | Show structured outputs |
