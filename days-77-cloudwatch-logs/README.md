# Day 77 — CloudWatch Logs

## What We Are Studying
CloudWatch Logs stores and searches log data from AWS resources and applications.
The CloudWatch Agent sends EC2 operating-system logs to a CloudWatch log group.

## Commands Used
| Command | Purpose |
|---------|---------|
| `aws logs create-log-group` | Creates a log group |
| `aws logs put-retention-policy` | Sets log retention |
| `aws logs describe-log-groups` | Verifies log groups |
| `aws logs describe-log-streams` | Verifies streams |
| `aws logs filter-log-events` | Reads log events |
