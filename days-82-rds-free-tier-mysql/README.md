# Day 82 — RDS Free Tier Setup (MySQL)
## What We Are Studying
Launch db.t3.micro MySQL via Console and CLI. Free tier: 750 hrs/month, 20 GB storage, single-AZ only.
## Commands Used
| Command | Purpose |
|---------|---------|
| `aws rds create-db-instance` | Launch MySQL instance |
| `aws rds describe-db-instances` | Check status |
| `aws rds delete-db-instance` | Clean up |
