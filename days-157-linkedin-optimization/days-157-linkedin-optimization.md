## Project Post 3 — DevOps Monitoring Suite

```text
I built a DevOps Monitoring Suite project to practice observability and incident response.

The project includes:
-  CloudWatch Agent monitoring
-  CPU, memory, and disk alarms
-  SNS email notifications
-  Daily S3 log backups using systemd timers
-  logrotate configuration
-  Incident runbooks and troubleshooting documentation

One useful lesson: my disk alarm initially showed INSUFFICIENT_DATA because the CloudWatch metric dimensions did not match the actual metric. After correcting them, the alarm became reliable.

Monitoring is not only about creating alerts; it is about making sure the right metric is collected correctly.
```
