# Day 115 — System Hardening
## What We Are Studying
System hardening reduces attack surface through automatic patches, least-privilege IAM, and port audits. These practices prevent common exploits and limit blast radius if compromised.
## Commands Used
| Command | Purpose |
|---------|---------|
| `sudo apt install unattended-upgrades` | Enable auto security patches |
| `aws iam create-policy` | Create minimal IAM policy |
| `sudo ufw status` | Audit firewall ports |
| `aws iam create-role` | Create IAM role |
