# Day 81 — RDS Fundamentals
## What We Are Studying
Managed databases (RDS) vs self-hosted on EC2. RDS handles backups, patching, failover; self-hosted gives full control but more ops work.
## Commands Used
| Command | Purpose |
|---------|---------|
| `aws rds create-db-instance` | Launch MySQL/Postgres instance |
| `aws rds describe-db-instances` | Check DB status |
| `aws rds delete-db-instance` | Clean up DB |
