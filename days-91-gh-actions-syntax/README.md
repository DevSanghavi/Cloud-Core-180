# Day 91 — GitHub Actions Syntax
## What We Are Studying
Learn on, jobs, steps, runs-on, and checkout actions to build CI/CD workflows in GitHub.
## Commands Used
| Command | Purpose |
|---------|---------|
| `git push origin main` | Trigger workflows on push events |
| `gh workflow run` | Manually trigger workflows |
| `cat .github/workflows/*.yml` | View workflow YAML files |
