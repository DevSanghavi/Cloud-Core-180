# Day 118/180 — Project 1, Day 3: EC2, RDS, and Security Groups
## Project: Terraform AWS Infrastructure
This project builds a secure AWS environment with Terraform, including a custom VPC, EC2 application server, private RDS database, security groups, and S3 remote state. The EC2 instance runs in the public subnet and RDS runs in the private subnet.
## Project Repository
[https://github.com/DevSanghavi/terraform-aws-infra](https://github.com/DevSanghavi/terraform-aws-infra)
All code for this day lives in the project repo above.
## Today
Created an EC2 t3.micro application server, RDS db.t3.micro MySQL database, and security groups controlling traffic between the internet, EC2, and RDS.
